# Fruit Catch — AdsGram build

## AdsGram
- Interstitial: `int-52381`
- Task: `task-52383`
- Rewarded: `52384`

Task находится в нижней части игрового экрана, сразу под кнопкой окончания игры. AdsGram управляет тем, какой рекламный креатив доступен; код не может гарантировать, что AdsGram будет менять рекламодателя. Task использует официальный `<adsgram-task>` компонент.

Rewarded: 5 подтверждённых Reward-событий → +10 000 очков, не чаще одного раза в UTC-день. Серверный Reward URL:
`https://YOUR-BACKEND-DOMAIN/adsgram/reward?userid=[userId]&key=YOUR_SECRET`

В AdsGram debug-просмотры не отправляют Reward URL, поэтому для реальной проверки серверного Reward нужен обычный учитываемый показ после настройки платформы.

## Gameplay changes
- Пропущенный обычный фрукт: -10 очков, но текущий раунд не ниже 0.
- Пропущенная бомба: без штрафа.
- Чем дольше длится игра, тем выше вероятность обычных и скрытых бомб.
- «Призрак» эффекта удалён.
- При попадании остаётся белая вспышка и белые искры именно в точке нажатия.
- Рабочий движок падения сохранён: `requestAnimationFrame()` + `translateY()`.

## Sound
Файлы положить в `frontend/assets/audio/`:
- `background.mp3`
- `fruit-pop.mp3`
- `bomb.mp3`
- `click.mp3`

Кнопка 🔊/🔇 сохраняет настройку. Музыка запускается после пользовательского действия из-за ограничений автозапуска браузера.

## Bot
Первый `/start` теперь показывает описание Fruit Catch и кнопку «Начать».
После «Начать» — выбор русского/туркменского языка.
После выбора языка — правила игры и кнопка открытия Mini App.

## Backend
Создай `.env` из `.env.example`:
- `BOT_TOKEN`
- `WEB_APP_URL`
- `ADSGRAM_REWARD_SECRET`
- `SQLITE_PATH`

Установка:
`py -m pip install -r requirements.txt`

Запуск:
`py -m uvicorn backend.main:app --host 0.0.0.0 --port 8000`

Для AdsGram Reward URL backend должен быть доступен публично по HTTPS.

## Important
Игровой общий баланс обычной игры пока остаётся localStorage-прототипом. Rewarded-поток имеет серверный учёт, но полноценная защита реального игрового баланса требует серверной проверки Telegram `initData`, игровых сессий и финального счёта.
