# Fruit Catch audio

Положи сюда свои MP3-файлы с такими именами:

- background.mp3 — фоновая музыка, желательно loop.
- fruit-pop.mp3 — один короткий звук для всех фруктов.
- bomb.mp3 — звук бомбы.
- click.mp3 — короткий звук кнопок.

Игра сама подключит эти имена.

Для поиска бесплатной/разрешённой для использования музыки можно посмотреть:
https://pixabay.com/music/
https://mixkit.co/free-stock-music/

Если файл отсутствует, игра продолжит работать без соответствующего звука.
